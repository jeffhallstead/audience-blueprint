# Recommendation Catalog Export

Produce a one-off downloadable file containing every recommendation the tool can
possibly surface, so you can review the full range before more users come through.
No changes to the app itself.

## What gets exported

**Blueprint rule catalog** (the deterministic engine behind the dashboard and roadmap):

- Category insights — one set per scoring category, per performance band (strong / developing / critical)
- Opportunity rules — the opportunity-matrix entries, with impact/effort and what triggers them
- Quick wins — short-horizon actions and their trigger conditions
- Long-term moves — structural actions and their trigger conditions
- Roadmap phase templates — the 30/60/90 phases for each maturity tier (foundational, scaling, advanced)
- KPIs — the metrics recommended per maturity tier
- Resources — supporting assets/links and when they appear
- CTAs and summary templates — closing recommendations per maturity tier

**Copilot objectives & prompts**:

- Each Copilot objective (label, description, document kind it produces, whether it's a primary objective)
- The 8 system strategy-library prompt templates (category, title, description, full prompt body)

Each row carries the condition that makes it appear (score band, category thresholds,
maturity tier) so you can see when a user would receive it.

## Format

One Excel workbook with a tab per group above, plus a flat "All Recommendations"
tab combining every item into a single reviewable list. A matching CSV of that
flat tab is included for quick filtering.

## Technical notes

- Source of truth: `src/lib/blueprint/rules.ts` (all rule groups), `src/lib/copilot/objectives.ts`,
  and the `prompt_templates` rows where `is_system = true`.
- Generated by a throwaway script that reads those definitions directly, so the export
  reflects the exact live copy — nothing rewritten or paraphrased.
- Output written to your documents area as a downloadable artifact.
- Not included: actual AI-generated recommendations from user sessions (you opted out),
  since those are freeform model output rather than a fixed catalog.
