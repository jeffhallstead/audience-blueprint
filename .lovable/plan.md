# Create a Price-Tiers Markdown Asset

Create a standalone markdown file that contains only the internal Signature Offer pricing tiers, formatted for easy copy/paste into proposals, emails, or internal notes.

## Deliverable

- `/mnt/documents/publisher-blueprint-price-tiers.md` — a clean markdown file with the five revenue brackets and matching monthly retainers.

## Content

```markdown
# Publisher Blueprint Signature Offer — Internal Price Tiers

Monthly retainer by client revenue bracket:

| Client revenue bracket | Monthly retainer |
| --- | --- |
| Under $10M | $3,500/month |
| $10M–$50M | $5,000/month |
| $50M–$150M | $7,500/month |
| $150M–$500M | $10,000/month |
| $500M+ | $12,500/month |

**Engagement terms:** 90 days, 60-minute sessions once a week.

The $10M–$50M bracket is the external anchor price used in the public deck.
```

## Steps

1. Create `/mnt/documents/publisher-blueprint-price-tiers.md` with the table above.
2. Verify the file renders correctly as markdown.
